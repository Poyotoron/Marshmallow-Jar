# シーンのライティング

Unity の新しいシーンは、屋外を想定したライティングになっています。
環境光は青寄り、Directional Light（太陽光）は黄寄りのため、そのままアバターの色を調整すると、
ワールドで見たときに**黄色っぽく**見えてしまいます。カメラも、既定の視野角では顔が歪んで見えます。

この機能は、シーンを**アバターの色味を確かめやすい設定**に整えます。

## 推奨の設定

| 対象 | 項目 | 値 |
|---|---|---|
| Lighting > Environment | Environment Lighting の Source | Gradient |
| Lighting > Environment | Sky / Equator / Ground Color | `#A0A0A0` / `#808080` / `#606060`（無彩色） |
| Lighting > Environment | Realtime Shadow Color | `#A0A0A0` |
| Directional Light | Rotation | X 40 / Y -145 / Z -20（右前上から当たる向き） |
| Directional Light | Color / Intensity | `#FFFFFF`（白） / 0.8 |
| Scene ビュー | カメラの Field of View | 40 |

!!! note "Directional Light が無いシーンでは、光源を追加しません"
    光源の項目は飛ばして、残りの設定だけを行います。

## 新しいシーンを作ったとき

`File > New Scene` で作ったシーンは、**確認なしで**推奨の設定になります。

## 既存のシーンを開いたとき

推奨の設定になっていないシーンを開くと、**確認ウィンドウ**が出ます。

| ボタン | 動作 |
|---|---|
| 変換する | 推奨の設定にする。シーンを**保存すると確定**します（自動では保存しません） |
| 今回はしない | このシーンでは、エディタを閉じるまで確認しない |
| このシーンでは確認しない | 次回以降も、このシーンでは確認しない |

確認ウィンドウを × で閉じた場合は「今回はしない」と同じです。

!!! info "確認ウィンドウが出ている間も、エディタは操作できます"
    確認ウィンドウはエディタを止めません。別のシーンを開くと、前のシーンの確認は取り下げられます（「今回はしない」扱いにはなりません）。

すでに推奨の設定になっているシーンでは、確認は出ません。次の場合も確認しません。

- 再生中、ビルド中
- 一度も保存していないシーン
- `Assets/` の外にあるシーン（パッケージのサンプルシーンなど）
- シーンを Additive で開いたとき

## メニューから選ぶ

確認ウィンドウと同じ操作を、メニューからも行えます。

| メニュー | 動作 |
|---|---|
| `Tools > Marshmallow Jar > Scene Lighting > Convert Active Scene` | いま開いているシーンを推奨の設定にする（確認ウィンドウが出ていなくても使えます） |
| `Tools > Marshmallow Jar > Scene Lighting > Skip This Time` | 「今回はしない」と同じ |
| `Tools > Marshmallow Jar > Scene Lighting > Don't Ask for This Scene` | 「このシーンでは確認しない」と同じ |

下の 2 つは、確認ウィンドウが出ているときだけ選べます。

## 設定画面のボタン

[設定画面](settings.md)の「シーンのライティングとカメラを整える」の下にボタンがあります。

| ボタン | 動作 |
|---|---|
| 今のシーンに適用 | いま開いているシーンを推奨の設定にする |
| 確認しないシーンをリセット | 「このシーンでは確認しない」を選んだシーンの一覧を空にする |

## 元に戻す

| 変更 | 元に戻す（Undo） |
|---|---|
| Directional Light の向き・色・強さ | 戻せます |
| Lighting（環境光と Realtime Shadow Color） | **戻せません**。Lighting ウィンドウで手動で戻してください |
| Scene ビューの視野角 | Scene ビュー右上のカメラ設定で戻してください |

シーンは自動で保存しないので、変換したあとに保存せず開き直せば、変換前の状態に戻ります。

## オフにする

[設定画面](settings.md)の「シーンのライティングとカメラを整える」を外すと、新しいシーンは Unity の標準どおりに作られ、確認も出なくなります。
