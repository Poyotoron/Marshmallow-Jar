# 完了通知

アップロードやパッケージのインポートなど、**時間のかかる処理が終わったときに、音と Webhook で知らせます。**
待っている間に別の作業をしたり、席を外したりしても、終わったことに気付けます。

設定は[設定画面](settings.md)の末尾の「完了通知」にあります。最初はオフです。
**時間のかかる処理が終わったら知らせる** をオンにすると使えます。

## 知らせるイベント

イベントごとに、音と Webhook をそれぞれオン・オフできます。

| イベント | 知らせるとき | 音 | Webhook |
|---|---|---|---|
| VRChat へのアップロード | VRChat SDK からのアップロードが成功・失敗したとき。ビルドに失敗したときも知らせる | オン | オン |
| Continuous Avatar Uploader の連続アップロード | 連続アップロードが**すべて終わったとき**に 1 回 | オン | オン |
| もちふぃった～ の衣装変換 | 変換が終わり、出力の Prefab ができたとき | オン | オン |
| Play モードへの切り替え | Play モードに入るまでに時間がかかったとき | オン | オフ |
| パッケージのインポートとスクリプトのコンパイル | `.unitypackage` のインポートやコンパイルに時間がかかったとき | オン | オフ |

表の「音」「Webhook」は最初の状態です。

!!! note "必要なもの"
    - 「VRChat へのアップロード」は VRChat SDK 3.10.0 以降（Avatars / Worlds のどちらでも）が必要です
    - 「Continuous Avatar Uploader の連続アップロード」は Continuous Avatar Uploader 0.3.8 以降（0.4.0 未満）が必要です

    入っていないときは、その行が灰色になります。

### まとめて知らせる処理

- **マルチプラットフォームのアップロード**（PC と Android など）は、すべてのプラットフォームが終わってから 1 回だけ知らせます。
- **Continuous Avatar Uploader** で連続アップロードしている間は、途中で起きるアップロード・Play モード・コンパイルの通知を出さず、すべて終わったあとに 1 回だけ知らせます。失敗があれば、その件数も知らせます。
  最後のアバターのアップロードが終わった時点で、Continuous Avatar Uploader の完了ダイアログの **OK を押す前に** 知らせます。元のプラットフォームに戻す設定にしていても、戻す切り替えは待ちません。
- **インポートのあとに続くコンパイル**は、インポートと合わせて 1 回にします。

### 短く終わったものは知らせません

「Play モードへの切り替え」と「パッケージのインポートとスクリプトのコンパイル」は、**知らせる最短の時間（秒）** より短く終わったときは知らせません。最初は 30 秒です（0〜600 秒）。
アップロードや変換は、時間によらず知らせます。インポートの失敗も、時間によらず知らせます。

## 音

| 項目 | 説明 |
|---|---|
| 成功したときの音 | 最初は Windows の通知音（`Windows Notify System Generic.wav`） |
| 失敗したときの音 | 最初は Windows のエラー音（`Windows Critical Stop.wav`） |

**選ぶ…** で好きな WAV ファイルに変えられます。**既定に戻す** で最初の音に、**鳴らす** で試しに鳴らせます。
ファイルが見つからないときは、ビープ音で知らせます。

!!! note "Windows 以外では、常にビープ音になります"

## Webhook

Webhook の URL を入れると、通知を Discord などに送れます。最初は Discord 向けの形式になっています。

### Discord に送る

1. Discord で、通知を受け取りたいチャンネルの **チャンネルの編集 > 連携サービス > ウェブフック** を開き、新しいウェブフックを作ります。
2. **ウェブフック URL をコピー** を押します。
3. 設定画面の **Webhook URL** に貼り付けます。入力欄は伏せ字で表示されます。
4. **テスト送信** を押して、チャンネルにテスト通知が届くことを確かめます。

成功は緑、失敗は赤の埋め込みで届きます。下部に、プロジェクトのフォルダ名と時刻が入ります。

### 送る内容を変える

送る内容は **Webhook で送る内容** で変えられます。**かんたん編集** と **JSON** の 2 つのタブがあり、どちらも同じ内容を編集します。
片方で変えると、もう一方にすぐ反映されます。**Discord 用に戻す** で最初の形式に戻ります。

#### かんたん編集

Discord に送る内容を、欄ごとに入力できます。

| 欄 | Discord での表示 | 空にしたとき |
|---|---|---|
| 送信者名 | 投稿者の名前 | ウェブフックの設定の名前になる |
| アイコンの URL | 投稿者のアイコン画像 | ウェブフックの設定のアイコンになる |
| メッセージ | 埋め込みの上に出る、ふつうのメッセージ | 出さない |
| タイトル | 埋め込みのタイトル | 出さない |
| 本文 | 埋め込みの本文 | 出さない |
| フッター | 埋め込みの下に小さく出る文字 | 出さない |

欄の下の **差し込む** のボタン（`{title}` `{message}` など）を押すと、最後に入力していた欄の**末尾**に、その書き方が入ります。
ボタンにマウスを乗せると、何に置き換わるかが表示されます。埋め込みの色は、成功なら緑、失敗なら赤になります。

!!! note "JSON で書き足した項目は残ります"
    JSON のタブで、かんたん編集に出ない項目（2 つ目の埋め込みなど）を書き足しても、かんたん編集で欄を変えたときに消えません。
    ただし、かんたん編集で欄を変えると、JSON の改行や字下げは決まった形に整えられます。

    JSON の書き方に誤りがあるときは、かんたん編集のタブに理由（何行目の何文字目か）が表示され、欄は編集できません。JSON のタブで直してください。

#### JSON

送る JSON を直接書きます。ほかのサービスに送る場合は、そのサービスの形式に書き換えてください。次の書き方が、送るときに置き換わります。

| 書き方 | 置き換わる内容 |
|---|---|
| `{title}` | 通知のタイトル（例: `アップロード完了`） |
| `{message}` | 本文（かかった時間などを含む） |
| `{result}` | `成功` / `失敗` |
| `{project}` | プロジェクトのフォルダ名 |
| `{time}` | 知らせた時刻（`2026-10-15 14:10:00` の形式） |
| `{color}` | 色の数値（成功 `5763719`、失敗 `15548997`）。Discord の埋め込みの色に使う |

`{color}` 以外は、JSON の文字列の中に置いてください（引用符などは自動でエスケープされます）。

!!! warning "Webhook の URL は他の人に見せないでください"
    URL を知っていれば、誰でもそのチャンネルに投稿できます。
    Marshmallow Jar は URL を Console に出さず、`ProjectSettings/` にも保存しません。

送信に失敗したときは、Console に `[Marshmallow Jar] Webhook の送信に失敗しました` と表示されます。

## プロジェクトごとに変える

Project Settings の「完了通知」では、イベントごとのオン・オフに加えて、**知らせる最短の時間・音・Webhook URL・送る内容**もこのプロジェクトだけ上書きできます。
たとえば、仕事用のプロジェクトだけ別の Discord チャンネルに送る、といった使い方ができます。

上書きの表示と戻し方は、ほかの項目と同じです（[上書きのしくみ](settings.md#override)）。
**テスト送信** と **鳴らす** は、そのページに表示している値で動きます。

!!! note "音・Webhook・時間の上書きは `UserSettings/` に保存されます"
    Webhook の URL を共有しないよう、また PC ごとに違う音のファイルの場所を共有しないよう、
    バージョン管理で共有しない `UserSettings/MarshmallowJar.asset` に保存します。
    同じプロジェクトを別の PC で開いた場合、この上書きは引き継がれません。

## 知らせられないこと

| 内容 | 理由 |
|---|---|
| もちふぃった～ の変換の失敗 | 失敗はダイアログでしか表示されず、外から分からないため |
| 「ビルドしてテスト」の成功、Unity のプレイヤービルド | 対象外です |
| Unity を閉じている間・再起動をまたぐ処理 | 通知は Unity の中で動いているため |

!!! note "Continuous Avatar Uploader のエラーやキャンセルは、ダイアログを閉じたあとに知らせます"
    ログインの失敗・プラットフォームの切り替えの失敗・想定外のエラー、および途中でのキャンセルでは、Continuous Avatar Uploader が先にダイアログを出します。
    この場合は、ダイアログの OK を押したあとに知らせます。

Continuous Avatar Uploader と もちふぃった～ の完了は、それぞれのツールが作るファイルを見て判定しています。
ツール側の更新で判定できなくなった場合は、[GitHub の Issues](https://github.com/Poyotoron/Marshmallow-Jar/issues) へ報告してください。
