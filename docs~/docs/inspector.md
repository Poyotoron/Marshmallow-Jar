# Inspector を別ウィンドウで開く

Inspector は、ほかのオブジェクトを選ぶと表示が切り替わります。2 つのオブジェクトを見比べたいときに不便です。

この機能をオンにすると、Inspector のヘッダー（名前・Tag・Layer の欄）の右下に **`別ウィンドウで開く`** ボタンが出ます。

## 使い方

1. 見たいオブジェクトを選びます。
2. Inspector の **`別ウィンドウで開く`** を押します。
3. そのオブジェクト専用のウィンドウが開きます。

開いたウィンドウは**そのオブジェクトに固定**されています。Hierarchy や Project でほかのものを選んでも、表示は変わりません。
ロックの操作はいりません。

ボタンはいくつでも押せるので、ウィンドウを何枚も並べられます。開いたウィンドウで値を変えると、元のオブジェクトに反映され、「元に戻す（Undo）」も使えます。

| 対象 | 開くもの |
|---|---|
| GameObject | その GameObject（全コンポーネント） |
| マテリアルやテクスチャなどのアセット | そのアセット |

!!! note "複数選択しているときは、ボタンは出ません"
    1 つだけ選んでいるときに表示されます。

## オフにする

[設定画面](settings.md)の「Inspector に「別ウィンドウで開く」ボタンを出す」を外すと、ボタンはすぐに消えます。
