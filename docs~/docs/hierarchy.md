# Hierarchy のチェックボックス

Hierarchy の GameObject の行の右端に、チェックボックスが 2 つ並びます。
**Inspector に移らずに**、オブジェクトの表示と EditorOnly を切り替えられます。

| 位置 | 意味 | チェックを入れると | 外すと |
|---|---|---|---|
| 左 | 表示（Active） | オブジェクトを表示する | 非表示にする |
| 右 | EditorOnly | タグを `EditorOnly` にする（アップロードに含めない） | タグを `Untagged` に戻す |

チェックボックスにマウスを乗せると、どちらの項目かが表示されます。

## まとめて切り替える

複数の GameObject を選択した状態で、**選択中の行**のチェックボックスを押すと、選択したすべてに同じ値が入ります。
選択していない行のチェックボックスを押した場合は、その行だけが変わります。

チェックボックスを押しても、行の選択は変わりません。

## 元に戻す

切り替えは「元に戻す（Ctrl + Z）」で取り消せます。
Prefab インスタンスで切り替えた場合は、Inspector の **Overrides** に変更として記録されます。

## EditorOnly が押せない行

タグが `Untagged` と `EditorOnly` 以外（`Player` や独自のタグなど）の行では、EditorOnly のチェックボックスが灰色になり、押せません。

!!! info "独自のタグを消さないための動作です"
    EditorOnly を外すとタグは `Untagged` になるため、独自のタグが付いた行で切り替えると、元のタグが失われてしまいます。
    複数選択でまとめて切り替えたときも、こうした行は変更されません。

## 位置を変える

既定では、行の右端から **56px** 空けた位置に並びます。右端には Prefab を開く「>」ボタンや、他の拡張が置くボタンが出ることが多いためです。

他の拡張のボタンと重なる場合は、[設定画面](settings.md)の **右端からの距離**（0〜200px）で動かしてください。
値を大きくするほど左へ寄ります。

!!! tip "名前が長いオブジェクトでは、名前の上にチェックボックスが重なります"
    Unity 本来の表示と同じく、行の幅が足りないときは文字の上に描かれます。気になる場合は Hierarchy の幅を広げてください。

## オフにする

[設定画面](settings.md)の「Hierarchy に表示 / EditorOnly のチェックボックスを出す」を外すと、チェックボックスはすぐに消えます。
