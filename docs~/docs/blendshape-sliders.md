# ブレンドシェイプのスライダー

Unity 標準の Inspector では、ブレンドシェイプのスライダーの範囲がメッシュで決まっていて（多くは 0〜100）、変えられません。

**BlendShape Sliders** ウィンドウでは、スライダーの**下限と上限を自由に決めて**ブレンドシェイプを動かせます。
100 を超えて強く効かせたいときや、狭い範囲で細かく調整したいときに使います。

!!! info "標準の Inspector はそのままです"
    このウィンドウは別に開くもので、標準の Inspector の BlendShapes 欄は変わりません。どちらで変えても同じ値が入ります。

## 開く

| 開き方 | 対象 |
|---|---|
| `Tools > Marshmallow Jar > BlendShape Sliders` | 選んでいるオブジェクトに追従する |
| SkinnedMeshRenderer のコンポーネントメニュー（⋮）の `BlendShape Sliders` | その SkinnedMeshRenderer に**固定**して開く |
| [設定画面](settings.md)の `ウィンドウを開く` | 選んでいるオブジェクトに追従する |

## 画面

上から順に並んでいます。

| 場所 | 説明 |
|---|---|
| `固定` | オンにすると、ほかのオブジェクトを選んでも対象が変わりません |
| 対象の欄 | いまの対象。SkinnedMeshRenderer をドロップすると、その対象に固定されます |
| 検索欄 | 名前の一部で絞り込みます（大文字・小文字は区別しません） |
| `0 以外` | 値が 0 でないブレンドシェイプだけを表示します |
| `下限` / `上限` | スライダーの範囲 |
| `0〜100` | 範囲を 0〜100 に戻します |
| スライダーの一覧 | ブレンドシェイプごとのスライダー |

範囲はプロジェクトに保存され、[設定画面](settings.md)の範囲と同じ値です。下限と上限は、少なくとも 1 離れるように自動で調整されます。

!!! warning "範囲の外の値は入力できません"
    スライダーの横の数値欄も、下限〜上限の中に収まります。
    範囲の外にある既存の値は、表示が端に寄るだけで、触らない限り書き換わりません。

## 元に戻す・Prefab・アニメーション

スライダーの変更は、標準の Inspector で変えたときと同じ扱いです。

- 「元に戻す（Ctrl + Z）」で取り消せます
- Prefab インスタンスでは、Overrides として記録されます
- Animation ウィンドウで録画中に動かすと、キーが打たれます

## 0〜100 の外の値が反映されないとき

Player Settings の **Clamp BlendShapes** が有効だと、0〜100 の外の値は Unity が 0〜100 に丸めます。
この状態で範囲を 0〜100 の外にすると、ウィンドウに注意が表示されます。
