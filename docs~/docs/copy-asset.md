# コピーを保存

マテリアルなどを別のフォルダに複製したいとき、Unity の「複製（Ctrl+D）」は同じフォルダにしか作れません。
複製してから移動・名前の変更をする手間がかかります。

この機能をオンにすると、アセットの Inspector のヘッダーの右下に **`コピーを保存…`** ボタンが出ます。
保存先と名前を選んで、そのアセットのコピーを 1 回で作れます。

## 使い方

1. Project ウィンドウで、コピーしたいアセット（マテリアルなど）を選びます。
2. Inspector の **`コピーを保存…`** を押します。
3. 保存のダイアログで、保存先のフォルダと名前を選んで保存します。

コピーができると、Project ウィンドウでそのアセットが一瞬強調されます。選んでいるアセットは元のままです。

| 項目 | 最初の値 |
|---|---|
| 保存先 | 元のアセットと同じフォルダ（パッケージの中のアセットは `Assets`） |
| 名前 | 元の名前に番号を付けたもの（例: `Base 1.mat`） |
| 拡張子 | 元と同じ |

!!! tip "パッケージの中のマテリアルを、自分のフォルダに持ってこられます"
    `Packages/` の中のアセットは、編集できなかったり、パッケージを更新したときに元に戻ったりします。
    `コピーを保存…` で `Assets/` にコピーしておけば、自分のものとして編集できます。

[Inspector を別ウィンドウで開く](inspector.md)もオンにしているときは、2 つのボタンが `コピーを保存…` `別ウィンドウで開く` の順に並びます。

## ボタンが出ないもの

| 対象 | 理由 |
|---|---|
| フォルダ | フォルダのコピーには対応していません |
| シーンに置いた GameObject | アセットではないため |
| FBX の中のマテリアルやメッシュなど、ほかのアセットの中に入っているもの | ファイルとして取り出す操作は対象外です |
| 複数選択しているとき | 1 つだけ選んでいるときに表示されます |

!!! note "同じ名前のファイルがあるときは、コピーしません"
    保存のダイアログで「上書きしますか」と聞かれて「はい」を選んでも、上書きはせずに理由を表示します。
    上書きすると、そのアセットを使っているマテリアルや Prefab との対応が崩れることがあるためです。別の名前を選んでください。

コピーは「元に戻す（Undo）」では取り消せません。不要になったら、Project ウィンドウで削除してください。

## オフにする

[設定画面](settings.md)の「Inspector に「コピーを保存…」ボタンを出す」を外すと、ボタンはすぐに消えます。
