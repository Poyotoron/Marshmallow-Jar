# Irodori Colorizer

**Irodori Colorizer** は、Project ウィンドウと Hierarchy ウィンドウの行に**色付きのラベル**を付ける機能です。
「配布物のフォルダ」「作業中の Prefab」などを色で見分けられるようにします。

以前は単体のパッケージとして配布していたもので、Marshmallow Jar に含まれるようになりました。
単体版を使っていた場合は[単体版からの移行](colorizer-migration.md)を参照してください。

## メニュー

右クリックメニューの **`Marshmallow Jar`** の下にあります。

| 場所 | 項目 | 動作 |
|---|---|---|
| Project ウィンドウ | `Set Label…` | ラベル一覧を開いて色を付ける |
| Project ウィンドウ | `Clear Label` | 色を外す |
| Project ウィンドウ | `Filter by Label…` / `Clear Label Filter` | 色で絞り込む / 解除する（[色で絞り込む](colorizer-filter.md)） |
| Hierarchy ウィンドウ | `Set Label…` | ラベル一覧を開いて色を付ける |
| Hierarchy ウィンドウ | `Clear Label` | 色を外す |

## 色を付ける

1. 色を付けたいフォルダ・アセット（Project）または GameObject（Hierarchy）を右クリックします。
2. **`Marshmallow Jar > Set Label…`** を選びます。
3. ラベル一覧が開くので、好きなラベルをクリックします。

クリックした瞬間に、その行が塗られます。
複数選択したまま右クリックすれば、**選択したすべてに同じラベルが付きます。**

!!! tip "まずは「触るな」から試すのがおすすめです"
    インポートしたまま書き換えたくない配布物のフォルダに **触るな**（茶色）を付けておくと、
    それだけで事故が減ります。

!!! warning "Prefab ではない GameObject に色を付けるときは、先にシーンを保存してください"
    未保存のシーンでは、オブジェクトを識別する情報が確定しないため色を付けられません。
    Prefab インスタンスのルートだけは、未保存でも色を付けられます。
    詳しくは[色の付き方](colorizer-behavior.md)を参照してください。

## ラベル一覧の見方

一覧は有効なプリセットごとに見出しで区切られ、上から順に並びます。

| 表示 | 意味 |
|---|---|
| 色チップ + ラベル名 | クリックすると、そのラベルが適用される |
| **✔** | いま選択している対象に、そのラベルが付いている |
| 一番下の入力欄 + **`＋`** | カラーコードから独自ラベルを追加して、そのまま適用する |
| **`ラベルを外す`** | 選択中の対象からラベルを取り除く |
| **`設定…`** | [Irodori Colorizer の設定](colorizer-settings.md)を開く |

一覧に何も出ない場合は、プリセットがすべて無効になっています。[プリセット](colorizer-presets.md)を確認してください。

## 色を外す

右クリック → **`Marshmallow Jar > Clear Label`**、またはラベル一覧の **`ラベルを外す`** を押します。

!!! warning "Prefab インスタンスの色を外すときは確認が出ます"
    シーン上の Prefab インスタンスに付いている色は、元の Prefab アセットに付いています。
    そのため外すと、**Project の表示と、シーン上の他のインスタンスからも色が消えます。**
    この場合は確認ダイアログが出るので、内容を読んでから実行してください。

## 独自のラベルを追加する

ラベル一覧の下部、または設定画面の「ラベル一覧」の最下部から追加できます。

1. カラーコードを入力します。`#RRGGBB` / `#RRGGBBAA` のほか、`red` のような色名も使えます。
2. **`＋`**（設定画面では **`追加`**）を押します。

名前を空のまま追加すると、カラーコードがそのまま名前になります。名前は後から設定画面で変更できます。

!!! note "追加したラベルだけが削除できます"
    同梱ラベルは削除できません。使わないものは、設定画面で個別に非表示にするか、プリセットごとオフにしてください。

## 色や名前を変えても、割り当ては外れません

ラベルは色や名前とは別に、内部で固有の識別子を持っています。
**色を変えても、名前を変えても、すでに塗った対象の割り当てはそのまま残ります。**
設定画面でラベルの色を変えるだけで、そのラベルを付けたすべての行の色が一度に変わります。

## 現時点でできないこと

- **Prefab の編集モード（Prefab ステージ）で開いた中身**には、シーン用の色は付きません。
- Prefab に付けた色は、**子オブジェクトには受け継がれません。** ルートだけが塗られます。
