# 困ったときは

## メニューが見当たらない

`Tools > Marshmallow Jar` が無い場合は、パッケージが正しく導入されていないか、
コンパイルエラーで読み込まれていない可能性があります。Unity の Console にエラーが出ていないか確認してください。

## 導入（または 0.2.0 に更新）したのに、何も起きない

最初は、すべての機能がオフです。`Tools > Marshmallow Jar > Preferences…` で、使う機能をオンにしてください。
0.1.0 から更新した場合も、オン・オフは全プロジェクト共通の全体設定に従うようになり、0.1.0 のオン・オフは引き継がれません（[インストール](install.md#update)）。

## 機能がオン・オフどちらになっているか分からない

`Tools > Marshmallow Jar > Project Settings…` を開いてください。チェックボックスは、このプロジェクトで実際に使われている値を表示しています。
青やオレンジの行は、このプロジェクトだけ上書きしている項目です（[上書きのしくみ](settings.md#override)）。

## 全体設定を変えたのに、このプロジェクトで変わらない

その項目を Project Settings で上書きしています。Project Settings のその行の **全体設定に戻す** を押すと、全体設定に従います。

## 完了通知が届かない

| 確認すること | 説明 |
|---|---|
| 「時間のかかる処理が終わったら知らせる」がオンか | [設定画面](settings.md)の「完了通知」 |
| そのイベントの「音」「Webhook」がオンか | 同じ表。Play モードとインポートの Webhook は最初はオフです |
| 「知らせる最短の時間」より長くかかったか | Play モードとインポート・コンパイルは、短く終わると知らせません |
| Webhook の **テスト送信** が届くか | 届かない場合は URL を確認してください。Console に失敗の理由が出ます |

詳しくは[完了通知](notifications.md)を参照してください。

## Hierarchy のチェックボックスが他のボタンと重なる

[設定画面](settings.md)の **右端からの距離** を大きくしてください。詳しくは[Hierarchy のチェックボックス](hierarchy.md)を参照してください。

## EditorOnly のチェックボックスが押せない

その行に `Untagged` / `EditorOnly` 以外のタグが付いています。独自のタグを消さないため、意図的に押せなくしています。

## Variant の名前に「Variant」が付いたままになる

| 心当たり | 説明 |
|---|---|
| 元の Prefab と同じフォルダに作った | 同じ名前のファイルがあるため、名前を変えずに残します |
| 作るときに自分で名前を入力した | 入力した名前を優先します |
| 以前から有る Variant | 新しく作った Variant だけが対象です |

詳しくは[Prefab Variant の名前](variant.md)を参照してください。

## シーンを開くたびに確認ウィンドウが出る

変換したあとシーンを保存していないと、次に開いたときも確認が出ます。変換したら保存してください。
そのシーンでは変換したくない場合は、**このシーンでは確認しない** を選んでください。

## 変換したシーンを元に戻したい

Lighting の設定は「元に戻す（Undo）」では戻りません。保存前であれば、保存せずにシーンを開き直すと元に戻ります。
詳しくは[シーンのライティング](scene-lighting.md)を参照してください。

## SDK に名前やサムネイルが入らない

順番に確認してください。

| 確認すること | 説明 |
|---|---|
| VRChat SDK - Avatars 3.10.0 以降が入っているか | 設定画面の項目が灰色なら、SDK が見つかっていません |
| 設定画面でオンになっているか | 「VRChat SDK に名前とサムネイルを自動入力する」 |
| 初めてアップロードするアバターか | 一度アップロードしたアバターでは何もしません |
| 欄が空か | 自分で入力した値は上書きしません |

## サムネイルが灰色一色になる

Scene ビューにアバターが映っていないか、Scene ビューのスカイボックスが非表示になっています。
Scene ビューでアバターを映してから、SDK の画面でアバターを選び直すか、サムネイル欄から撮り直してください。

## ブレンドシェイプを 100 より大きくできない

[ブレンドシェイプのスライダー](blendshape-sliders.md)の **上限** を上げてください。
それでも反映されない場合は、Player Settings の **Clamp BlendShapes** が有効になっています。

## Irodori Colorizer の色が付かない

| 確認すること | 場所 |
|---|---|
| 単体版の Irodori Colorizer が入っていないか | 入っていると Marshmallow Jar 側は止まります（[単体版からの移行](colorizer-migration.md)） |
| 「Irodori Colorizer を使う」がオンか | [設定画面](settings.md) |
| 「Project ウィンドウ」「Hierarchy ウィンドウ」がオンか | [Irodori Colorizer の設定](colorizer-settings.md)の「表示」 |
| そのラベルが非表示になっていないか | 同「ラベル一覧」 |
| そのラベルのプリセットがオフになっていないか | 同「プリセット」 |

!!! warning "Console に「シーンを保存してから…」と出た場合"
    未保存のシーンでは、Prefab 以外の GameObject に色を付けられません。
    シーンを保存してから、もう一度ラベルを設定してください。

## Project ウィンドウの行が暗いまま戻らない

[色で絞り込む](colorizer-filter.md)が有効になっています。
右クリック → `Marshmallow Jar > Clear Label Filter` で解除してください。Unity を再起動しても解除されます。

## それでも解決しない

再現手順を添えて、[GitHub の Issues](https://github.com/Poyotoron/Marshmallow-Jar/issues) へ報告してください。
Unity のバージョンと、Console に出ているメッセージがあると調査が早くなります。
