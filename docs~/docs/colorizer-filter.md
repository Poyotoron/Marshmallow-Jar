# 色で絞り込む

Project ウィンドウで、**選んだ色のラベルが付いたものだけを目立たせます。**
それ以外の行は暗く表示されます（行は消えません）。

## 使い方

1. Project ウィンドウで右クリックし、**`Marshmallow Jar > Filter by Label…`** を選びます。
2. ラベルの一覧が開くので、絞り込みたい色にチェックを入れます。複数選べます。
3. チェックを入れた時点で、Project ウィンドウの表示が変わります。

一覧の外をクリックすると閉じます。絞り込みは閉じたあとも続きます。

## 暗くならないもの

| 行 | 理由 |
|---|---|
| 選んだ色のラベルが付いたフォルダ・アセット | 絞り込みの対象そのもの |
| 選んだ色のラベルが付いた**フォルダの中身** | フォルダに付けた色は、中身にも効きます |
| それらの**親フォルダ**（`Assets` まで） | 目的のアセットまでたどれるように |

複数の色を選んだときは、どれか 1 つでも当てはまれば暗くなりません。

リスト表示・アイコン（グリッド）表示・左側のフォルダツリーのどれでも同じように働きます。

## 解除する

次のどちらかで解除できます。

- 右クリック → **`Marshmallow Jar > Clear Label Filter`**
- 一覧の下にある **`すべて解除`**

!!! info "絞り込みは、Unity を閉じると解除されます"
    絞り込みは一時的な表示なので、設定ファイルには保存しません。スクリプトの再コンパイルでは解除されません。

## 絞り込み中に色を付け直したとき

絞り込み中にラベルを付けたり外したりすると、表示はすぐに更新されます。
たとえば赤で絞り込んでいるときに、別のアセットに赤を付けると、そのアセットと親フォルダが明るくなります。

## 使えないとき

`Filter by Label…` が灰色で選べない場合は、[設定画面](settings.md)の **Irodori Colorizer を使う** と、
[Irodori Colorizer の設定](colorizer-settings.md)の「Project ウィンドウ」がオンになっているか確認してください。
