# VRChat SDK への自動入力

初めてアバターをアップロードするときは、VRChat SDK の画面で名前とサムネイルを入れる必要があります。
この機能は、それを**自動で入れます。**

| 欄 | 入る内容 |
|---|---|
| Name | SDK の画面で選んでいるアバターの、シーン上の名前（GameObject の名前） |
| Thumbnail | そのときの **Scene ビュー**をその場で撮った画像（1200×900） |

## 必要なもの

VRChat SDK - Avatars 3.10.0 以降（4.0.0 未満）。入っていないプロジェクトでは、この機能は使えません。

## 自動で入る条件

| 条件 | 説明 |
|---|---|
| 初めてアップロードするアバターである | アバターの Pipeline Manager にまだ Blueprint ID が無いこと。一度アップロードしたアバターでは何もしません |
| 欄が空である | 名前とサムネイルのうち、**空の欄だけ**を入れます。自分で入れた値は上書きしません |

SDK の画面（`VRChat SDK > Show Control Panel` の Builder タブ）でアバターを選んだときに入ります。

!!! tip "サムネイルは Scene ビューの見た目そのままです"
    SDK の画面を開く前に、Scene ビューでアバターを撮りたい構図にしておいてください。
    背景は Scene ビューの表示設定（スカイボックスの有無など）に従います。
    気に入らなければ、SDK の画面のサムネイル欄から撮り直せます。

## 別のアバターに切り替えたとき

SDK は「初めてアップロードするアバター」の入力内容を 1 組しか覚えていないため、
アバター A で入力した名前が、続けて選んだアバター B の画面にも残ります。

Marshmallow Jar が A のために**自動で入れた値**がそのまま残っている場合は、B の名前と、B を選んだときの Scene ビューの画像に入れ直します。
**自分で入力した値**の場合は、そのまま残します。

## オフにする

[設定画面](settings.md)の「VRChat SDK に名前とサムネイルを自動入力する」を外すと、名前とサムネイルは入らなくなります。
